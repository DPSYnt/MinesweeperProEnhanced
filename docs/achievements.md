# MinesweeperEX 成就

当前源码保留 16 项成就，取消误排后，安全格排雷输入不记为错误，也不影响成就。“完美胜利”沿用无排雷错误的原条件，因此当前规则下随胜利解锁；“毫发无伤”要求没有引爆地雷。电脑版在“对局记录 → 会话成就”中查看解锁状态与条件，手机在“记录”中查看已解锁成就。成就和累计清雷数在本次程序运行期间保留，重新开始不会清空，退出程序后重置。已交付的 Android 1.1 APK 仍使用原成就条件。

| 成就 | 解锁条件 |
| --- | --- |
| 首次胜利 | 首次获胜 |
| 完美胜利 | 没有排雷错误的情况下获胜；安全格输入已忽略，当前随胜利解锁 |
| 快速胜利 | 在第 5 回合及以前获胜 |
| 扫雷大师 | 本次运行累计清除 100 颗地雷 |
| 国王守护者 | 保留国王雷并清除其他全部地雷获胜 |
| 内鬼大师 | 在同一回合解除两个内鬼区的干扰 |
| 幸存者 | 以 1 HP 获胜 |
| 连锁反应 | 一次爆炸实际清除至少 5 颗地雷 |
| 排雷初体验（新增） | 首次正确排除一颗非国王地雷 |
| 排雷能手（新增） | 单局正确排除 50 颗地雷 |
| 排雷老兵（新增） | 本次运行累计清除 500 颗地雷 |
| 生命充盈（新增） | HP 达到 100 |
| 开拓者（新增） | 控制区达到棋盘面积的一半 |
| 地狱征服者（新增） | 在地狱难度获胜 |
| 噩梦征服者（新增） | 在噩梦难度获胜 |
| 毫发无伤（新增） | 没有引爆地雷的情况下获胜；可主动结束回合，安全格排雷不影响解锁 |

排除和爆炸实际清除的地雷均计入累计清雷数。内鬼雷引爆后再生不撤销已发生的清雷计数。重复点击已排除的格子不会重复计数或重复解锁。
