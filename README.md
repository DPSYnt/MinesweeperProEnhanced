# MinesweeperEX

项目仓库：[DPSYnt/MinesweeperProEnhanced](https://github.com/DPSYnt/MinesweeperProEnhanced)。开发和提交流程见 [开发与维护](CONTRIBUTING.md)；推送与拉取请求会自动运行 Java 21 桌面回归检查。

Java 21 + Swing 桌面扫雷游戏。在会收缩、增殖和重新布局的棋盘中逐步扩张，清除其他全部地雷、场上仅剩国王雷时获胜；提前引爆或排除国王雷立即失败。支持普通、困难、地狱、噩梦四档难度、移动国王雷、内鬼区、爆炸动画、图解规则、历史、统计和成就。

## 开始游戏

电脑脚本版已取消安全格排雷惩罚和全部有解保障，并优化连续鼠标输入与大棋盘刷新。Android 源码已同步规则，等待打包指令。现有 `dist/MinesweeperEX-Android-1.1.apk` 保留原交付内容，仍有安全格误排惩罚及初始数字推理保证；旧 1.0.4 EXE / APK 保留供历史对照。运行及打包说明见 [运行与安装说明](docs/distribution.md)。

需要 **JDK 21 或更高版本**。Windows 下双击根目录的 **`run.cmd`**，会自动编译并启动游戏，不需要 Maven 或第三方依赖。脚本依次查找 `JAVA_HOME`、本项目已下载的 JDK 和 `PATH` 中的 JDK；当前项目已具备本地 JDK，可直接启动。也可运行 `.\scripts\build.ps1 -Run -JdkHome 'JDK目录'` 指定位置。

启动后显示开始菜单，可选择难度、查看“规则与操作”或退出。对局中通过“返回菜单”或 `Ctrl+N` 返回；有进行中的对局时，主按钮为“继续当前对局”，另设“开始新游戏”按所选难度替换当前对局。上一局已结束时只显示开始游戏，并保留该局记录。查看菜单不改变棋盘，计时仍按本局实际经过时间计算。

对局页面只保留“对局记录 / 规则与操作 / 返回菜单”三个导航入口，结束回合和重新开始在侧栏操作。旧的顶部菜单栏、重复教程入口、独立终局地图和只展示技术信息的关于窗口已移除。

“对局记录”将本局统计、行动记录和会话成就集中到一个窗口，首次启动无对局时隐藏入口。记录在行动后更新，也可手动刷新，刷新保留当前标签页。规则和记录窗口重复打开时会激活已有窗口。游戏结束后可查看记录、返回菜单或直接查看当前棋盘上的完整终局，无须另开地图副本。

已构建的游戏也可直接运行：

```powershell
java -jar .\target\MinesweeperEX.jar
```

## 难度与初始雷数

| 难度 | 棋盘 | 普通雷 | 内鬼雷（核心） | 国王雷 | 初始总雷数 | 初始 HP | 每颗引爆地雷扣血 | 区外普通雷增殖 |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 普通 | 18×18 | 67 | 2 | 1 | **70** | 5 | 1 | 12% |
| 困难 | 25×25 | 157 | 2 | 1 | **160** | 4 | 2 | 15% |
| 地狱 | 30×30 | 267 | 2 | 1 | **270** | 3 | 3 | 18% |
| 噩梦 | 35×35 | 397 | 2 | 1 | **400** | 2 | 4 | 20% |

每局设两个内鬼区，每区含一颗内鬼雷（即核心），其余均为普通雷。区域尺寸依次为 4×4 / 6×6 / 8×8 / 10×10，每区初始总雷数为 7 / 13 / 19 / 26。内鬼雷仅在区域内部随机生成，避开最外层一圈；普通雷可在全区随机分布。

开始菜单、规则表和实际放雷共用难度配置。侧栏统计全部雷种的当前剩余数量。区外普通雷按现存数量的比例增殖，新增量向下取整，并受可用位置限制；区内普通雷不随环境变化增殖、重排。

## 快速上手

1. 清除其他全部地雷、场上仅剩国王雷时获胜，无须揭开全部安全格。提前排除国王雷、直接引爆或使其被周围爆炸波及，均立即失败。HP 耗尽，或环境变化后控制区少于 20 格，也判定失败。
2. 开局揭开左上 5×5 安全区。其余地雷随机分布，不保证每一步均可由数字推断，也不会自动修复布局。仅可操作已揭开区域八方向相邻的未知格，绿色边缘表示可操作范围。
3. 左键探索，右键排雷。正确排雷清除目标并恢复 1 HP，HP 上限为 100，达到上限后仍可正常清雷；除核心外同时揭开该格。右键点击未揭开的安全格无响应，不扣血、不计行动、不触发环境变化。手机端单击探索、长按排雷。
4. 引爆地雷仅影响以该格为中心的 3×3 范围，不连锁扩散。引爆或结束回合后，若对局尚未结束，依次收缩控制区、移动国王雷、增殖并重排普通雷、更新数字。
5. 内鬼区安全数字为真实邻雷数随机 ±1，限制在 0～8。只有正确排除内鬼雷（核心）才解除本区干扰，不揭开该格，其余地雷与揭开状态不变。内鬼雷不受周围爆炸波及；直接点中时爆炸扣血，随后在本区内部的未知无雷格再生，始终避开最外层，干扰保留。区内普通雷正常参与排除和爆炸。
6. 数字为 0 且无干扰的已揭开格可辅助展开。对局中可随时重新开始，终局可重新选择难度。

两端共用简明规则正文，分别说明鼠标与触屏操作。电脑端 `F1` 规则页分为“基本规则 / 难度配置 / 特殊地雷”，保留数字、扩张、收缩及辅助展开示意图。完整规则见 [游戏规则](docs/rules.md)。

## 界面与操作

浅色卡片界面将棋盘与信息栏分开呈现。侧栏显示生命值、控制区、全部剩余雷数、清雷统计与坐标情报；控制区以格数、百分比和小进度条共同展示。右侧固定操作面板以大号字体显示本局计时，结束回合和重新开始按钮始终可见，终局后只禁用结束回合。悬停浮窗、实时坐标文字与底部实时状态栏已移除，仍保留格子及行列高亮。棋盘按难度动态创建，大棋盘可滚动查看，桌面格子保持正方形且不小于 18 像素。行列刻度从 1 开始，与国王情报、无障碍说明和行动记录一致：普通 1～18、困难 1～25、地狱 1～30、噩梦 1～35。

| 操作 | 功能 |
| --- | --- |
| 左键 / 右键 | 揭开 / 直接排雷 |
| 在已揭开格上同时按左右键 | 预览周围未知格，在原格松开任意一键时辅助展开 |
| 在已揭开格上双击左键 | 使用相同辅助展开规则 |
| 悬停 | 高亮格子和对应行列，不显示浮窗提示 |
| 滚轮 | 纵向滚动大棋盘 |
| Shift + 滚轮 | 横向滚动 |
| Ctrl + 滚轮；棋盘工具栏 − / + | 缩放，格子范围 18–42 像素 |
| 适应 | 恢复随窗口尺寸自动缩放 |
| 方向键 | 移动焦点，滚动至对应格子 |
| Enter / 空格；F | 揭开焦点格；排除焦点格的雷 |
| Ctrl + Enter | 结束回合 |
| Ctrl + N | 返回开始菜单 |
| Ctrl + H | 查看对局记录 |
| F1 | 查看规则与操作 |

本作右键直接清雷，因此数字会随剩余地雷减少；**数字归零时**，等价于经典扫雷已标完周围地雷，可以一次展开相邻未知格。数字未归零或仍受内鬼干扰时不执行展开。每次辅助只计一次行动，不结束回合。

鼠标按下预览，松开执行。同格内轻微拖动有效，拖出后松开取消。快速连续右键逐次处理，不会误当双击辅助；丢失松开事件后，下一次按下可以直接恢复。左右键辅助在第一键松开时只结算一次，第二键松开不会重复执行；未知格上的双击第二下和左右键组合不会误触。重复显示同一棋盘或仅刷新计时不会打断按压，真正换盘、失焦及动画开始才取消手势。爆炸动画期间暂停棋盘和结束回合输入。行动历史和成就集中在“对局记录”查看，共 16 项成就，具体条件见 [成就说明](docs/achievements.md)。

## 构建与验证

```powershell
.\build.cmd -Test -Preview
```

构建脚本以 `--release 21 -encoding UTF-8 -Xlint:all -Werror` 编译代码，执行同一套无第三方依赖的回归测试，导出界面预览并生成 **`target/MinesweeperEX.jar`**。省略 `-Test` 只编译打包；`-Run` 在构建后启动游戏。

`-Preview` 导出 `target/start-menu.png`、`start-menu-compact.png`、`game-normal.png`、`game-hard.png`、`game-hell.png`、`game-nightmare.png`、`chord-preview.png`、`informer-core-before.png`、`informer-core-after.png`、`informer-core-records.png`、`rules-preview.png`、`rules-tab-1.png`、`rules-tab-2.png`、`records-tab-0.png` 至 `records-tab-2.png` 和基础鼠标状态预览。内鬼图展示同一真实局面排除核心前后的变化，图片均由真实 Swing 面板绘制。

可选 `-DesktopTest` 使用系统鼠标短暂打开真实窗口，验证基础鼠标手势与焦点，并在完成后关闭窗口、恢复鼠标位置；仅建议在空闲交互桌面中手动运行。本次改动验证使用严格编译、无窗口规则和 Swing 交互检查及图片核对，未运行该桌面选项。

PowerShell 也可直接调用：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1 -Test -Preview
```

如已安装 Maven 3.9+，可运行 `mvn clean verify`，生成同名 JAR；首次构建需要下载 Maven 插件。Maven 测试阶段执行 `RegressionSuite`，`mvn -DskipTests package` 可跳过测试。IDEA / Eclipse 可导入 `pom.xml`，运行 `com.minesweeper.MinesweeperApplication`。

回归测试覆盖四个难度共 800 个固定种子的随机初始棋盘、安全格排雷完全无响应、普通动作不移动其他雷或收起已揭开格、HP 上限与受伤后恢复、新成就及跨局累计、实际雷数、核心避开最外层、区域约束、提前排除或引爆国王立即失败、波及国王与清空全部地雷仍失败、仅剩国王获胜、揭开全部安全格仍有其他雷时不获胜、最后一颗普通雷或核心的结算、内鬼雷的爆炸豁免与内部再生、正确排除解除干扰、区内普通雷保留、辅助展开、同时收缩、增长容量、时间冻结与控制器回调。Swing 检查覆盖快速连续点击、丢失松开后的恢复、同盘计时刷新保留按压、左右键与双击辅助、动画输入保护、四档大棋盘、菜单、记录刷新、滚动缩放及多尺寸布局。

引擎复用不可变快照与探索队列，单颗排雷只更新邻近数字，界面计时直接读取用时；坐标轴复用字体并局部更新。控制器防止重复动画回调、旧结果干扰重开，以及无效操作引发的整盘刷新。回归检查覆盖这些状态边界，并对四个难度共 120 条固定种子操作轨迹核对当前规则基线；历史比较保留在优化记录中。

可选性能探针：`java -Xms128m -Xmx512m -cp 'target/classes;target/test-classes' com.minesweeper.EnginePerformanceProbe`。探针打印行为摘要和重复快照读取耗时，不以机器速度判断测试是否通过。具体改动、测量范围和结果见 [代码优化记录](docs/optimization.md)。
